### Technical notes for future copy passes

- **Encoding:** File is UTF-8 with CRLF. Use `[System.IO.File]::ReadAllText/WriteAllText` with `[System.Text.Encoding]::UTF8` for all edits — the Edit tool fails on multi-line CRLF matches and on mojibake byte sequences.
- **Odometer JS:** Stats bar uses `data-count` attributes and animates to that number. Only integers work — no text strings.
- **Swiper sliders:** The Swiper.js loop mode duplicates slides in the DOM. Each slide appears twice. Regex replacements run on the full string so both copies are updated in one pass.
- **Mojibake in original template:** Original Bizox copy had Windows-1252 bytes mis-read as UTF-8, producing chars like `â€œ` (which in memory are U+00E2 U+20AC U+0153). Target them with regex against the `<p class="xb-item--content">` wrapper rather than matching the exact byte sequence.
